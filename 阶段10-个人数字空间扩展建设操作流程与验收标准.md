# 阶段10-个人数字空间扩展建设操作流程与验收标准

## 一、文档目的

本文档用于指导阶段10开发执行。

阶段10目标：

将 dpxspace 从个人开发者作品展示网站，扩展为：

> 一个记录开发、探索、兴趣和成长过程的个人数字空间。

开发必须按照：

阶段10.1 → 验收 → 阶段10.2 → 验收 → 阶段10.3 → 验收

的流程执行。

未经当前阶段验收通过，不得进入下一阶段。

------------------------------------------------------------------------

# 二、整体开发流程

## 第1步：开发准备

开发前确认：

-   阅读《阶段10-个人数字空间扩展建设指导方案》
-   确认当前开发阶段
-   检查已有系统是否正常运行
-   备份当前代码

需要确认：

    React项目正常运行

    Supabase连接正常

    后台管理系统正常

    阶段9功能无异常

------------------------------------------------------------------------

# 第2步：建立开发计划

Claude Code执行前需要明确：

本阶段：

    目标：

    需要修改：

    需要新增：

    预计影响：

禁止：

-   同时开发多个阶段
-   修改无关模块
-   删除已有功能

------------------------------------------------------------------------

# 第3步：执行开发

开发过程中必须遵守：

## 文件管理规则

每新增文件夹：

必须创建：

    说明.md

说明：

-   文件夹作用
-   包含内容
-   与其他模块关系

------------------------------------------------------------------------

## 代码修改规则

每次修改：

记录：

-   修改文件
-   修改原因
-   修改内容
-   影响范围

------------------------------------------------------------------------

## 数据库规则

新增数据库：

必须：

1.  创建 migration 文件
2.  记录字段说明
3.  测试数据库操作

------------------------------------------------------------------------

# 第4步：阶段开发完成

完成后生成：

    阶段10.x开发记录.md

内容：

包括：

## 1. 本阶段目标

## 2. 完成内容

## 3. 新增文件

## 4. 修改文件

## 5. 数据库变化

## 6. 遇到的问题

## 7. 解决方案

## 8. 测试结果

------------------------------------------------------------------------

# 第5步：提交验收

提交：

-   开发记录
-   项目代码
-   测试结果

等待验收。

验收通过：

进入下一阶段。

------------------------------------------------------------------------
