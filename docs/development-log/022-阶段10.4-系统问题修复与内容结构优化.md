# 022-阶段10.4-系统问题修复与内容结构优化

**日期**: 2026-07-24

## Phase 1: 修复 Storage

### 数据库
- **新增**: `supabase/migrations/010_storage_fix.sql`
  - gallery 和 coffee_logs 表增加 `storage_path` 字段
  - Storage bucket 权限策略：authenticated 可 INSERT/DELETE，public 可 SELECT

### 类型更新
- GalleryItem 增加 `storage_path: string`
- CoffeeLogData 增加 `storage_path: string`

### 上传逻辑重构
- `gallery.service.ts` — uploadImage 支持子文件夹参数（archive/coffee/projects），返回 `{url, path}`
- `deleteImage` 改为接受 `storagePath` 而非 image_url
- GalleryManage — 上传图片存入 `archive/` 子文件夹
- CoffeeManage — 上传图片存入 `coffee/` 子文件夹
- 删除记录时通过 storage_path 精确删除 Storage 文件
