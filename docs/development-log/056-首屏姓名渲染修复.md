# 第 056 次开发记录 — 首屏姓名字符渲染成团修复

## 开发时间

2026-10-18

## 本次目标

修复首页进入时“丁鹏翔”三个字短暂缩成一团的渲染问题，同时消除伴随的首屏卡顿感。

## 背景

阶段11完成后，用户反馈首页首次进入时姓名会缩成一团。该问题不影响布局，但首帧视觉异常明显。

## 修改文件

新增：无

修改：

- `src/pages/Home.tsx` — 姓名改为每个字符独立持有渐变；保留逐字淡入上移
- `src/index.css` — `.text-gradient` 改为 `.text-gradient-char`，移除父级渐变与 `gradient-pan` 动画

删除：无

## 根因

原实现把渐变放在 `<h1>` 上（`background-clip: text`），每个字符 `<span>` 单独执行 `opacity` 与 `transform` 动画。采样显示字符布局始终正常（各 70px，x = 144 / 214 / 284），但 Chromium 在合成子层时会把父级渐变裁切成一小块，视觉上即“缩成一团”。

对照实验：

- 父级渐变 + 子字符 opacity/transform：❌ 成团
- 单个文本节点整体动画：✅ 正常
- 子字符静态、父级整体动画：✅ 正常
- 每个字符自己持有渐变 + 子字符动画：✅ 正常

## 解决方案

1. 移除 `<h1>` 上的 `text-gradient`，改为 `.text-gradient-char` 应用于每个字符 span。
2. 每个字符按序号计算 `background-size: 字符数 × 100%` 与 `background-position`，使三段渐变在视觉上连续。
3. 保留原有逐字动画（0.3s 起始延迟、50ms 间隔、0.4s 上浮淡入）。
4. 使用 `Array.from(name)` 遍历，避免代理对字符被拆分。
5. 移除不再使用的 `gradient-pan` 动画；渐变改为静态，视觉连续但不再缓慢流动。
