# 029-阶段10.6-Coffee展开状态修复

**日期**: 2026-07-24

## 问题 (BUG-003)
CoffeeDetail 的展开状态存储在组件内部 `useState`。当后台排序数据变化时，React reconciliation 可能导致展开状态映射到错误的 item。

## 修复
将展开状态从子组件提升到父组件：
- Coffee 页用 `expandedId: number | null` 追踪当前展开的记录 ID
- CoffeeDetail 改为受控组件：接收 `isOpen` + `onToggle` props
- 排序后 ID 不变 → 展开状态始终指向正确记录

- TypeScript: 0 错误
