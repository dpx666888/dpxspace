# 024-阶段10.6-图片上传稳定性加固

**日期**: 2026-07-24

## 问题背景
图片上传可正常使用，但存在稳定性隐患。

## 修复内容

### 1. 文件校验（新增）
- **文件**: `src/services/gallery.service.ts`
- 文件类型白名单：仅允许 JPG/PNG/WebP/GIF
- 文件大小限制：最大 5MB
- 超限时抛出明确中文错误提示

### 2. 文件名冲突（修复）
- 添加随机6位后缀避免并发上传文件名冲突
- `Date.now()-randomStr-filename`

### 3. 错误提示（改进）
- `GalleryManage.tsx`、`CoffeeManage.tsx`
- `alert('上传失败')` → `alert(err.message)` 显示具体原因
- 例如："图片过大（6.2MB），请压缩至 5MB 以内"

### 4. Storage删除（加固）
- `deleteImage` 从 `console.warn` 吞错 → 抛出异常
- 调用方可感知删除失败（目前用 `.catch(() => {})` 容错处理）

- TypeScript: 0 错误
- Vite build: 成功
