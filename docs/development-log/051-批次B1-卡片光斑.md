# 第 051 次开发记录 — 批次 B1 卡片跟随光斑

## 开发时间

2026-10-18

## 本次目标

为项目、实验室、个人空间卡片增加跟随指针的光斑与边框高光，替换原有单一的 hover 上浮效果。执行依据：`docs/plans/阶段11-UI动效优化执行标准.md` 批次 B1。

## 背景

B2a/B2b 已完成卡片结构与封面定稿，B1 在其上套用交互容器，避免先做光斑再因 Bento 改结构而返工。

## 完成内容

1. 新增 `SpotlightCard`：卡片根节点承载边框、圆角、背景与 hover 上浮；内部渲染光斑层与边框光斑层，指针位置通过 CSS 变量驱动。
2. 光斑尺寸按卡片区分：Bento 大卡 560px，普通卡片 360px，`sm` 预留给后续小卡片。
3. 指针事件按帧合并：同一帧内多次 `pointermove` 只更新一次，组件卸载时取消未执行的 rAF。
4. 仅在 `(hover: hover) and (pointer: fine) and (prefers-reduced-motion: no-preference)` 下渲染光斑层；触摸设备与 reduced-motion 下完全不渲染。
5. `focus-visible` 时隐藏边框光斑，改为在卡片根节点显示 2px accent ring + 2px offset，避免与默认 outline 叠加成双边框，同时解决 outline 被 `overflow-hidden` 裁剪的问题。
6. 新增 `data-spotlight-card`、`data-spotlight="glow|border"` 标识，供验收脚本精确定位，避免把 `var(--spotlight-size)` 误判为卡片根节点。

## 遇到的问题

1. 首次诊断“个人空间最后一个卡片层数为 0”：选择器 `div[style*="--spotlight-size"]` 同时匹配到了光斑层内联样式里的 `var(--spotlight-size)`，把光斑层误当成卡片根节点；功能本身正常。
2. 键盘聚焦时默认 outline 被卡片 `overflow-hidden` 裁掉，视觉上看不到聚焦描边。

## 解决方案

1. 给卡片根节点增加 `data-spotlight-card`，验收脚本改用该属性定位；重新统计后 Home 3 张、Projects 3 张、Lab 2 张、个人空间 2 张，均为 2 个光斑层。
2. 在 `focusVisible` 状态为真时给根节点加 `ring-2 ring-accent/70 ring-offset-2 ring-offset-bg-primary`；root 自身的 box-shadow 不被 `overflow-hidden` 裁剪，截图确认聚焦环清晰可见。
