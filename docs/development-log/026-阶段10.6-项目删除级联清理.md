# 026-阶段10.6-项目删除级联清理

**日期**: 2026-07-24

## 问题 (BUG-004)
删除项目时仅删除 projects 表记录，不清理关联数据：
- `ai_collabs` 中以 `project_id` 关联的记录成为孤儿数据
- `project_timeline` 中关联的记录成为孤儿数据

## 修复
`src/services/projects.service.ts` — `deleteProject()` 增加级联清理：
1. 先删除 `ai_collabs` 中 `project_id = id` 的记录
2. 再删除 `project_timeline` 中 `project_id = id` 的记录
3. 最后删除项目本身
4. 清理失败不阻断主流程（console.warn 记录）
