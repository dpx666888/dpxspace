# 023-阶段10.6-新建页面loading修复

**日期**: 2026-07-24

## 问题
后台点击"新建项目/新建实验室/新建成长日志"后页面无限loading，无法进入新建表单。

## 根因
loading 条件 `listLoading || (!isNew && !lab && labs)` 在新建场景下仅依赖 `listLoading` 变量。当 React Query 缓存数据或异常场景下 `listLoading` 状态不确定时，可能导致永久loading。

## 修复方案
将 loading 条件拆分为两个独立检查：
1. `listLoading` → 显示loading spinner（新建和编辑共用）
2. `!isNew && !item` → 编辑模式下未找到记录，显示"未找到"提示
3. 其他情况 → 正常渲染表单

## 修复文件
- `src/admin/pages/ProjectEdit.tsx` — 新建/编辑项目
- `src/admin/pages/LabEdit.tsx` — 新建/编辑实验
- `src/admin/pages/LogEdit.tsx` — 新建/编辑日志

## 附带改进
- 编辑模式下找不到记录时，不再显示永久loading，改为显示"未找到该记录"并提供返回列表链接
