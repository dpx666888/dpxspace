## 本次目标

为前台每个页面设置独立的 `<title>` 与 `description`，替代全局单一标题，提升 SEO 与浏览器标签辨识度。

修改：

- `index.html` — **移除静态 `<title>`**
- `src/pages/Home.tsx`、`About.tsx`、`Projects.tsx`、`ProjectDetail.tsx`、`Lab.tsx`、`Log.tsx`、`Contact.tsx`、`Gallery.tsx`、`Space.tsx`、`Coffee.tsx`、`NotFound.tsx` — 每个页面各渲染分支均加入 `<PageMeta>`

删除：无

## 完成内容

1. 新增 `PageMeta` 组件，内部输出 `<title>{title}</title>` 与可选 description
2. 11 个前台页面接入，标题规则：
   - 首页：`丁鹏翔 - 个人开发者电子名片`
   - 其余：`<模块名> | 丁鹏翔`
   - 项目详情：动态 `{project.title} | 丁鹏翔` + 该项目的 description
   - 404：`404 - 页面不存在 | 丁鹏翔`
3. 每个页面的 **加载分支、错误分支、主渲染分支** 均放置 PageMeta——因为 React 19 在组件卸载时会移除其提升的 `<title>`，若某分支不渲染 Meta，该状态下标题会为空

## 遇到的问题

**React 19 的 `<title>` 提升是「追加式」，不会去重也不移除 `index.html` 里的静态 `<title>`。** 若保留静态 title，`document.title` 取第一个 `<title>`（即静态的），每页标题将全部失效。

二手资料确认：React 官方 `<title>` 文档明确"同一时刻只应渲染一个 `<title>`，多个同时渲染时浏览器行为未定义"。

## 解决方案

1. **移除 `index.html` 的静态 `<title>`**，由 React 独占管理（`grep -c "<title>" index.html` = 0）
2. **确保任一时刻只有一个页面挂载**：页面过渡用 `AnimatePresence mode="wait"`，退出动画完成后才挂载新页面，不会出现两个 PageMeta 并存
