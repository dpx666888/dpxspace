## 二、逐项详情

### 10.7.1 — 新建内容修复

**问题**: 点击"新建项目/实验室/成长日志"无法进入空表单，显示"未找到记录"

**根因**: loading 条件 `listLoading || (!isNew && !item && items)` 在新建场景下依赖于单一的 `listLoading` 变量

**修复文件**:
- `src/admin/pages/ProjectEdit.tsx`
- `src/admin/pages/LabEdit.tsx`
- `src/admin/pages/LogEdit.tsx`

**修复方案**:
```tsx
// 修复前：复杂布尔条件
if (listLoading || (!isNew && !lab && labs)) { return <Loading /> }

// 修复后：拆分为独立分支
if (listLoading) { return <Loading /> }          // 数据加载中
if (!isNew && !lab) { return <NotFound /> }      // 编辑模式找不到
// 其他情况 → 正常渲染表单
```

### 10.7.3 — AI协作项目选择器

**问题**: 关联项目使用 "文字输入 + 数字ID" 双字段，容易出现：
- "智能监控系统" / "智能监控 项目" / "智能监控平台" 三种写法指同一项目
- 手动输入 project_id 容易出错

**修复文件**: `src/admin/pages/CollabManage.tsx`

**修复方案**:
```tsx
// 修复前
<input value={editData.project} placeholder="项目名称" />
<input type="number" value={editData.project_id} placeholder="数字ID" />

// 修复后
<select value={editData.project_id} onChange={...}>
  <option value="">无关联项目</option>
  {projects?.map(p => <option value={p.id}>{p.title}</option>)}
</select>
```
选择后自动填充 `project_id` 和 `project` 名称。

**前端展示**: `ProjectDetail.tsx` 按 `project_id` 过滤 AI 记录并在项目详情页渲染。
