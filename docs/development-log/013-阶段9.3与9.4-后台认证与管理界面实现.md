## 遇到的问题

1. 后台编辑项目时的 `story` 等 JSONB 字段需要管理员手动维护 JSON，交互不够友好
2. `ProjectEdit` 编辑模式需要按 id 查找项目，当前服务层只有 `getProjectBySlug`，因此从项目列表缓存中查找
3. 管理页面较多，表单代码重复度高

## 解决方案

1. 阶段9.4 先以 JSON 文本框实现功能完整，后续阶段可升级为动态表单控件
2. 通过 `useProjects()` 获取列表后在编辑页 `find` 匹配 id，避免新增按 id 查询接口
3. 提取统一的表单样式（input/select/textarea/button），保持代码可读性，暂不做过度抽象
