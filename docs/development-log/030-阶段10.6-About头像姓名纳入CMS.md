# 030-阶段10.6-About头像姓名纳入CMS

**日期**: 2026-07-24

## 问题 (BUG-012)
About 页头像URL和姓名从静态 `data/profile.ts` 读取，无法通过后台修改。

## 修复
- HomePageConfig 新增 `avatar_url` 字段
- About.tsx 改用 `useHomeConfig` 获取头像和姓名，移除 `data/profile` 静态导入
- 无头像时显示 User 占位图标
- SiteConfigManage 后台新增头像URL输入框

## 数据流
```
后台首页配置 → site_config.value.avatar_url → About页头像 + 首页Hero姓名
```

## 修改文件
- `src/types/database.ts` — HomePageConfig 增加 avatar_url
- `src/pages/About.tsx` — 移除静态 profile，改用 CMS 数据
- `src/admin/pages/SiteConfigManage.tsx` — 新增头像URL字段
- `src/data/fallbackData.ts` — avatar_url 默认值

## 构建
- TypeScript: 0 错误
