# 第 052 次开发记录 — 批次 C 终端卡片与技术栈跑马灯

## 开发时间

2026-10-18

## 本次目标

将 Hero 右侧的抽象装饰替换为会打字的终端卡片；技术栈由静态 pill 改为无限滚动跑马灯。执行依据：`docs/plans/阶段11-UI动效优化执行标准.md` 批次 C。

## 背景

A 批完成氛围层后，Hero 右侧仍是几个抽象色块，无法传递“我是谁”；技术栈区一排静态 pill 缺乏动感。

## 修改文件

新增：

- `src/components/TerminalCard.tsx` — 终端窗口、逐字打字、3D 倾斜与眩光
- `src/components/Marquee.tsx` — CSS 无限滚动容器，双向内容复制

修改：

- `src/pages/Home.tsx` — Hero 右侧替换为 TerminalCard；技术栈区接入 Marquee
- `src/index.css` — 新增 `.marquee`、`.marquee-track`、`.terminal-cursor` 与 keyframes；reduced-motion 下停止

删除：无

> 说明：计划中 C 批为 3 个文件，实际 4 个。跑马灯与光标需要全局 keyframes，按项目现有样式组织方式放入 `index.css`，未新增依赖，仍在单批 ≤5 个代码文件限制内。

## 完成内容

1. 终端脚本固定为三组命令：`$ whoami` / `$ stack` / `$ status`，输出分别为身份、技术栈与在读状态。
2. 打字机挂载后延迟 500ms 开始，按 30ms/字逐字播放，播完停止；滚动离开再回来不重播。
3. `prefers-reduced-motion: reduce` 下不启动定时器，首帧直接显示完整文本；光标保持可见但不闪烁。
4. 指针设备上终端可 ±6° 倾斜并带跟随眩光；触摸设备与 reduced-motion 下不启用。
5. 技术栈改为 CSS 跑马灯：内容复制两份、30s 线性循环、两侧渐隐遮罩、hover 暂停；reduced-motion 下完全停止。
6. 终端正文固定最小高度，打字过程不引起布局位移。

## 遇到的问题

1. 验收脚本需要区分终端卡片与普通容器，避免误选。

## 解决方案

1. 终端根节点使用 `select-none rounded-xl` 组合定位；配合 `pre` 文本与 `.marquee-track` 计算样式完成验证。
