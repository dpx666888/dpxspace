# 025-阶段10.6-section_order安全过滤

**日期**: 2026-07-24

## 问题 (BUG-002)
`section_order` 中可能包含无效 key（遗留数据、手动修改等），导致前端渲染空白。

## 修复方案：前端保护 + 后台清理

### 前端（About.tsx）
- `rawOrder.filter(key => key in sectionLabels)` 仅渲染已知模块

### 后台（AboutManage.tsx）
- 加载时过滤：`loaded.filter(key => key in sectionLabels)` 清理历史脏数据
- 保存时过滤：`sectionOrder.filter(key => key in sectionLabels)` 防止写入无效key

### 数据流
```
DB读取 → filter(.sectionLabels) → 渲染/编辑
编辑保存 → filter(.sectionLabels) → DB写入
```
