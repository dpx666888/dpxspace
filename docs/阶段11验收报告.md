## 已知问题

1. **D2 不实施**：本项目使用 `<BrowserRouter>` 声明式路由，`<Link viewTransition>` 不会触发 `document.startViewTransition`。评估证据见第 054 号开发记录；未改路由架构。
2. **主包仍有 >500KB 警告**：当前 753KB raw / 216KB gzip。阶段11未继续拆分（超出本阶段范围），后续可评估 framer-motion 与 superset 依赖的分包。
3. **既有安全/功能问题未处理**（不在本阶段范围）：SEC-01 草稿项目公网可见、SEC-02 注册权限、BUG-02 编辑后缓存不失效、BUG-03 拖拽 upsert 约束风险。详见 `docs/问题报告-2026-10-18.md`。
4. **Google Fonts 外链风险**：Space Grotesk / JetBrains Mono / Inter / Noto Sans SC 均来自 fonts.googleapis.com；网络受限时会回退到系统字体。若部署环境访问不稳定，建议后续自托管字体。
5. **光斑强度偏克制**：属于主观审美项，如需更明显可在 `SpotlightCard` 中调整光斑透明度与半径。
6. **后台登录页无独立 title**：既有问题，未在本阶段处理。
