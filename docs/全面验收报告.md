## 七、问题汇总

### 7.1 与 UI.md 的差异（功能已实现，形态不同）

1. **组件未独立拆分**：UI.md 规划了 NavLink、ProjectCard、LabCard、LogCard、SkillTag、Timeline、SectionTitle 等独立组件，实际代码直接内联在页面中。功能等效，后续如需复用可再拆分。
2. **Home 页缺少"最新日志"区域**：UI.md 要求展示最近3条成长日志摘要，当前未实现。
3. **Home 页 Hero 缺少右侧装饰元素**：UI.md 规划有装饰元素，当前仅左侧文字。
4. **Home 页技术栈使用文字标签而非图标**：UI.md 要求"图标展示主要技术方向"。
5. **首屏未实现字符级动画**：UI.md 要求标题"逐个字符淡入，间隔50ms"，当前是整个元素淡入。
6. **viewport 未配置 `-50px` margin**：UI.md 要求 `viewport={{ once: true, margin: "-50px" }}`，实际为 `viewport={{ once: true }}`。

### 7.2 内容缺失

7. **C++ 项目档案全为占位符**：`story` 所有字段均为【待补充】。
8. **Git 项目档案全为占位符**：同上。
9. **AI 协作记录全为占位符**：`aiCollabs.ts` 所有记录均为【待补充】。
10. **`src/data/profile.ts` 缺失**：CORE.md 要求存在，个人信息目前硬编码在 About.tsx 中。

### 7.3 资源缺失

11. **项目无封面缩略图**：所有项目卡片无图片。
12. **实验室无缩略图**。

14. **favicon 仍为 Vite 默认**：`/vite.svg` 未替换为个人网站图标。
