## 项目故事

### 项目背景（story_why）

```
作为一名学生开发者，我需要一个能完整展示个人项目、学习历程和 AI 协作成果的窗口。市面上没有完全满足需求的名片方案，于是决定从零搭建属于自己的个人网站，同时通过内容管理系统实现在线维护内容。
```

### 设计方案（story_design）

```
采用前后端分离架构：React 19 + Vite + Tailwind CSS v4 构建前台展示层，Supabase 提供 PostgreSQL 数据库、身份认证、对象存储与行级安全策略。数据访问遵循"页面 → Hooks → Services → Supabase"三层分层，前后台复用同一套数据层。后台路由 /admin 通过认证守卫保护。
```

### 开发过程（story_development）

```
从数字名片起步，历经 10 个阶段的迭代建设：完成首页、关于我、项目、日志、实验室等核心模块后，逐步扩展出个人空间框架、视觉档案、咖啡角、AI 协作记录系统。先后完成 Supabase 接入、后台管理系统、图片上传体系、拖拽排序系统，并通过多轮 Bug 审查与稳定性修复。
```

### 遇到的问题（点击「添加问题」逐条添加）

1. **标题**：`HTML5 拖拽排序在表格行上失效`
   **描述**：`表格 <tr> 的 onDragOver 缺 preventDefault，且 <a> 标签原生拖拽会拦截 dragstart，改为卡片式布局、所有拖拽事件放在同一 div、编辑按钮改用 button`

2. **标题**：`竖拍照片在固定比例容器中被裁剪`
   **描述**：`object-cover 强制填充 16:9 容器会裁掉高图上下部分，改为 w-full h-auto 按原比例完整显示`

3. **标题**：`后台只显示已发布项目，草稿无法管理`
   **描述**：`getProjects() 去掉 .eq('status', 'published') 过滤，恢复后台对全部状态项目的可见性`

### 解决方案（story_solutions）

```
通过分阶段迭代 + 系统性 Bug 审查保障质量：每阶段生成开发记录并验收后再继续；图片上传前置类型与大小校验；编辑页加加载守卫与"未找到"兜底；环境感知 logger 在生产静默；Supabase 未配置时优雅回退本地静态数据。
```

### 项目成果（story_result）

```
上线可访问的个人网站（www.dpxspace.com），含前台展示、后台管理、拖拽排序、图片上传、AI 协作记录、视觉档案、个人空间、咖啡角等完整功能，配套 38 篇开发记录与 11 个数据库迁移脚本。
```

### 项目总结（story_summary）

```
完整经历了一个全栈个人网站从需求分析、架构设计、迭代开发到部署上线的全流程，深入掌握了 React 生态、TypeScript、Supabase 与工程化实践，也沉淀了与 AI 协作开发的高效工作流。
```
