# 阶段10-个人数字空间扩展建设指导方案

## 一、阶段背景

当前 dpxspace 已完成：

-   个人开发者展示网站建设
-   项目作品展示系统
-   成长日志系统
-   AI协作记录系统
-   后台内容管理系统

网站已经具备"开发者作品集"的基础能力。

但是，目前网站主要展示的是：

> 我创造了什么。

下一阶段需要进一步展示：

> 我是谁，以及是什么组成了现在的我。

因此进入：

# 阶段10：个人数字空间扩展建设

目标：

将 dpxspace 从"个人作品展示网站"升级为：

> 一个记录开发者创造、探索、兴趣和成长过程的个人数字空间。

------------------------------------------------------------------------

# 二、阶段目标

## 总体目标

新增个人空间体系，包括：

1.  视觉档案系统（Visual Archive）
2.  个人空间入口（Personal Space）
3.  Coffee Lab 咖啡角

最终形成：

    DPX Space

    ├ 首页
    │
    ├ 关于我
    │
    ├ 项目档案
    │
    ├ 实验室
    │
    ├ 成长日志
    │
    ├ 视觉档案
    │
    └ 个人空间
        │
        ├ 咖啡角
        ├ 阅读记录（未来）
        ├ 我的设备（未来）
        └ 更多兴趣模块

------------------------------------------------------------------------

# 三、核心设计理念

## 1. 不做普通兴趣展示

禁止设计成：

    我喜欢咖啡
    我喜欢音乐
    我喜欢摄影

这种普通个人介绍。

应该保持 dpxspace 原有理念：

    探索

    ↓

    实践

    ↓

    遇到问题

    ↓

    调整

    ↓

    记录

    ↓

    成长

例如：

项目：

记录开发过程。

咖啡：

记录制作探索过程。

学习：

记录成长过程。

------------------------------------------------------------------------

# 四、阶段10开发原则

## 原则1：所有内容必须后台可管理

新增内容必须支持：

-   新增
-   修改
-   删除
-   排序

禁止：

直接写死在代码中。

------------------------------------------------------------------------

## 原则2：图片作为基础资源

图片不是某个页面独占。

设计：

    Gallery资源中心

            ↑

    项目

    咖啡角

    日志

    实验室

同一张图片可以被多个模块引用。

------------------------------------------------------------------------

## 原则3：保持现有技术架构

继续使用：

前端：

-   React
-   Vite
-   React Router

后端：

-   Supabase
-   PostgreSQL
-   Storage

状态：

-   React Query

不引入新的大型框架。

------------------------------------------------------------------------
